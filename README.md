#  Uzwa Portfolio

A modern and responsive personal portfolio website showcasing my projects, technical skills, learning journey, and growth as a Computer Science student.

🔗 **Live Website:** https://uzwashahid.github.io/uzwa-portfolio/

---

## About

This portfolio was designed and developed from scratch to reflect my journey as a developer. It highlights my featured projects, technical skills, personal story, and ways to connect with me.

The website follows a clean, journal-inspired aesthetic with smooth animations and an interactive user experience.

---

## Features

- Responsive design for desktop and mobile
- Smooth scrolling and scroll-based animations
- Interactive project showcase
- Video demonstrations for featured projects
- Animated typewriter effect
- Light/Dark mode toggle
- Skills and learning journey sections
- Contact and social links
- Resume download

---

- HTML5

- JavaScript (Vanilla)
- GitHub Pages

## Running Locally

1. Clone the repository

```bash

```

2. Open the project folder.

3. Launch `index.html` in your browser.
